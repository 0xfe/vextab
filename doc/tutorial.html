The VexTab Tutorial

Fourteen steps to writing notation and guitar tablature with VexTab

What is VexTab?

With VexTab you can write the same guitar phrase as notes on a staff or as fret numbers on strings. You enter the music as text, and VexTab draws the score.

Each example has its own editor. Change a pitch in the first bar, then use the later lessons to give the phrase rhythm, chords and expression. The interactive user guide also lets you play each example.

Step 1: Your first notes

Start on middle C and play one note per beat. In Cn4, the letter names the note, n asks for a natural, and 4 gives its octave. The voice starts in quarter notes, so these four pitches fill one bar. Change the last F#5 to F#4 and listen for the same ending an octave lower.

staff { Cn4 D4 E4 F#5 | }

A guitarist can enter the same kind of phrase by specifying where to put each finger. In 4/3, the 4 is the fret and the 3 is the string, counting from the high E. Replace the first three positions with 4-5-6/3. You should still hear three separate attacks before the move to string four.

guitar { 4/3 5/3 6/3 10/4 | }

By default a guitar part shows the pitches above the fret numbers. The example below uses view tab to show the strings alone. Change it to view notation to read the pitches, then to view both to match each pitch to its fret.

guitar { view tab 4-5-6/3 10/4 | }

When you have only the beginning of a phrase, put it inside fragment {}. Type 4/3 between the inner braces. The sketch can end there even though the measure has beats left.

guitar { view tab fragment {} }

To spell a pitch on the staff, put the accidental before the octave. Try Gb4 and G#4 in the first example and compare the signs beside G. A double flat is Gbb4, a double sharp is G##4, and an explicit natural is Gn4.

Step 2: Stave keywords

This phrase stays on the low sixth string. The bass clef makes its pitches easy to read, while the four flats and the cut-time sign come from key Ab and meter cut. Change the clef to treble and compare where the notes sit. The frets stay at four and five.

Choose the tuning before entering frets because it determines which pitch each fret produces. Alongside standard, dropD and eb, you can list the open strings from highest to lowest with tuning (E5 B4 G4 D4 A3 E3). Other clefs include alto and tenor. A key can be minor, as in key F#m, and the meter can be a fraction or a sign such as meter common.

guitar { meter cut clef bass key Ab fragment { 4/6 5/6 } }

Step 3: Rests and barlines

Count four beats in the opening guitar bar. You play on one, two and three, then leave beat four silent. The word rest takes the current note duration, so the barline | still falls after four beats.

In the second score, repeatStart and bar repeatEnd enclose the passage to repeat. The rest has an explicit position, rest[line 0]. On the next row, bar repeatBoth closes one repeat and opens another. Change bar final to bar double and compare the last two lines at the right edge.

guitar { 4/3 5/3 6/3 rest | 5/3 4/3 2/3 2/2 | }
staff { repeatStart C4 D4 E4 rest[line 0] bar repeatEnd break system C4 D4 E4 rest bar repeatBoth C4 D4 E4 F4 bar final }

Step 4: Bend a few notes

On the third beat, pick fret six and bend the string up one semitone. The mark belongs to the last fret in 4-5-6/3. Its rise=1/1 takes the whole note. Compare the bend on the next row, which rises two semitones by halfway through the note and returns to the fretted pitch by the end.

guitar { view tab :q 4-5-6/3[bend +1 rise=1/1] 10/4 | 5/3 4/3 2/3 2/2 | break system 6/3 7/3[bend +2 rise=1/2 release=1] 7/4 rest | 9-8-7-6/2 | }

Step 5: Mutes, strokes and vibrato

In bar two, play a downstroke, an upstroke and a muted downstroke. The x/3 gives the third stroke its dead sound. The names sd and su come from the aliases above the guitar part. Change the definition of v to "vibrato wide" and look at the wavy line in both bars. Lines beginning with # are comments.

# Aliases alias v="vibrato" alias su="stroke up" sd="stroke down" # Create a guitar stave guitar { 4/3 5/3 6/3[bend +1 rise=1, v] 10/1 | 5/3[sd] 4/3[su] x/3[sd] 2/2[v] | }

Step 6: Add some chords

Play C, E and G together on beat one, then play the same pitches one at a time. Parentheses make the first three pitches a chord, so they take only one beat together. Change E to E-flat inside the parentheses and listen for the difference between the opening chord and the three notes that follow.

staff { (C4 E4 G4) C4 E4 G4 | }

On the first guitar chord, hold fret eight on string two while string three bends and releases. The bend sits inside the parentheses next to 7/3, so only that string changes pitch. In the next chord, both frets carry a bend.

alias bendup="bend +1 rise=1" guitar { tabStems off fragment { (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[bendup] 5/3[bendup]) 7/4 | (5/2 6/3 7/4) } }

Step 7: Hammer-ons, pull-offs, taps and slides

On string four, tap fret twelve and pull off first to seven, then to five. Each [p] marks the fret you arrive at. A hammer-on or a slide names its destination the same way. Follow the next [h] back up to fret seven, then find the slide from fret five to three on string five.

alias h="hammer" p="pull" gl="slide" v="vibrato" guitar { view tab fragment { :q (5/2 5/3 7/4) 5/3 6/3[h] 7/4 | 12/4[tap] 7/4[p] 5/4[p] 7/4[h] 7/5 5/5 3/5[gl] | break system (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[bend +1 rise=1] 5/3[bend +1 rise=1])[v] 7/4 0/4[gl] | (5/2 6/3 7/4)[v] | break system (5/4 5/5) (7/4[gl] 7/5[gl]) (5/4[gl] 5/5[gl]) (5/4 5/5) 7/5[h] | (12/5 12/4)[tap] (5/5[gl] 5/4[gl]) 3/5[bend +1 rise=1] 5/6[vibrato wide] } }

Step 8: Durations and tuplets

Count the three opening frets evenly on beat one. The :8 selects eighth notes, and tuplet 3:2 fits three of them into the time of two. The chord just outside the braces gets a new duration, :q, so it enters on beat two.

Once you set a duration, following notes in the same voice inherit it. The last beat divides into a dotted eighth (:8.) and a sixteenth (:16). Move the dot from the eighth to the sixteenth and the bar becomes too short. Put it back to restore four beats. A duration change inside a tuplet lasts only to its closing brace. Other durations include :w for a whole note, :h for a half and :32 for a thirty-second.

meter 4/4 guitar { key Ab tuning eb :8 tuplet 3:2 { 5/5 7/5[slide] 8/5[slide] } :q (5/2 6/3) 7/3[hammer] :8. 5/4 :16 5/5 | }
alias gl="slide" half="bend +1 rise=1" guitar { fragment { :q (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[half] 5/3[half])[vibrato] :8 7/4 12/4[gl] :16 9/4[tap] :8 3/4[gl] :16 0/4[gl] } }

Step 9: Lyrics and annotations

Sing “Fi-Ga-Ro!” with the first three notes. Each note carries its own label in brackets, so the syllables follow the triplet. Change below to above on “Fi” and look for the one syllable that moves.

The second phrase uses labels for playing instructions. Replace the italic “sweep” with “dolce” to change the instruction at that attack. For a chord name use symbol. For words that need a hyphen or span several notes, use lyric, as in the Slow river lead sheet.

meter 4/4 guitar { key Ab tuning eb :q tuplet 3:2 { 5/5[label "Fi" below] 5/4[label "Ga" below] 5/3[label "Ro!" below] } :h 4/4[label "Blah!" above] | }
guitar { key A (5/2 5/3 7/4)[label "A7#9" above] 5/3 6/3[hammer] 7/4 | :8 7/4[label "sweep" style italic] 6/3 5/2 3/1[vibrato] :q 7/5[label "P.H." font "Arial" size 10 style bold] :8 3/5 5/5[slide] | }

Step 10: Staccatos, fermatas and more

The dot under the opening C asks for a short attack. On the fourth row, the fermata over E asks the player to linger. Change staccato below to staccato above. The dot moves across the note, while C still occupies one beat. Use the captions under the other notes to match each sign to its name.

meter 3/4 staff { C4[staccato below] E4[articulation "av" below] G4[accent below] | break system B4[articulation "a-" below] C5[articulation "a^" above] rest | break system E5[articulation "a+" above] G5[articulation "ao" above] rest | break system C4[articulation "ah" below] E4[fermata above] G4[articulation "a@u" below] | break system B4[articulation "a|" below] C5[articulation "am" above] rest | text names size 12 line 11 { "Staccato" "Staccatissimo" "Accent" | "Tenuto" "Marcato" skip | "Left hand pizzicato" "Snap pizzicato" skip | "Open" "Fermata" "Inverted fermata" | "Up bow" "Down bow" skip | } }

Step 11: Timed text and musical symbols

The harmony changes only twice while the guitarist plays four attacks. Give the chord names their own rhythm in text harmony. Each name lasts a half note, so “A Major” lines up with the held note on beat three.

In the third example, chord names sit above the staff and a sentence sits below it. Each text lane counts its own beats. Replace the first "Em" with skip to leave that half bar blank without moving “G7”. Higher line values place a lane lower. Choose align left, align center or align right to position words around their beat. In the last example, start and end anchor signs to the edges of the bar.

meter 4/4 guitar { key Ab tuning eb :q tuplet 3:2 { 5/5 5/4 5/3 } :h 4/4 | text harmony line 10 { :h "G Minor" "A Major" | } }
staff { key Ab :8 C4 D4 E4 F4 G4 A4 B4 C5 | text syllables line 10 { :8 "Do" "Re" "Mi" "Fa" "Sol" "La" "Ti" "Do" | } }
staff { C4 D4 E4 F4 | G4 A4 B4 C5 | text chords line -1 { :h "C" "Em" | "G7" "C" | } text words line 11 { :w "This is a new text line." | skip | } }
staff { repeatStart C4 D4 E4 F4 bar repeatEnd G4 A4 B4 C5 | text road line -2 { start sign coda :h. skip :q sign tr end sign segno | :w skip | } text volume line 9 { :w sign f | skip | } text words line 13 { :w skip | :h skip "D.S. al coda" | } }

Step 12: Write rhythms with slash notation

A rhythm player can read when to strum from slashes and what to play from the chord name above them. Count a half note, a quarter and a rest under G Maj7. In bar two, the first two eighths have opposite stroke marks. A [slash] on a pitch sets the head at that pitch, while slash writes an unpitched beat.

staff { clef percussion :h B4[slash, stroke down] :q B4[slash] rest | :8 B4[slash, stroke down] B4[slash, stroke up] :q tuplet 3:2 { B4[slash] B4[slash] B4[slash] } :q slash | text harmony line -2 { :w "G Maj7" | "Am" | } }

Step 13: Customize the appearance

The first example enlarges one note for a lesson. Change scale 2 to scale 1 and compare the notehead and staff lines. The pitch and its quarter-note duration stay the same.

In the last example, increase staffDistance 50 to give the low notes more room above the tab. Set the score width in pixels. Use rowGap for space between systems, the rows of staves that a player reads together.

layout { width 200 scale 2 } guitar { view notation fragment { :q 5/5 } }
guitar { key A (5/2 5/3 7/4)[label "A7#9" above] 15/1 16/1[hammer] 20/1 | }
layout { staffDistance 50 scale 0.8 } guitar { key A fragment { (5/2 5/3 7/4) rest 0/6 1/6[hammer] 0/1 } }

Step 14: Give tablature stems

When a guitarist reads tab alone, stems and beams show how long each fret should sound. VexTab normally leaves them off. Here view tab and tabStems on let you count the three opening frets as a triplet without a second staff.

Switch the stem direction between tabDirection up and tabDirection down. Find the same triplet beam on the opposite side of the strings, then follow the slides into the final vibrato.

guitar { view tab tabStems on tabDirection up key A fragment { :8 tuplet 3:2 { 5/5 5/4 5/3 } :16 5/1 6/1 7/1 8/1 :8 9/1 10/1[slide] :h 9/1[slide, vibrato] } }
