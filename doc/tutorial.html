The VexTab Tutorial

Sixteen steps to writing notation and guitar tablature with VexTab

What is VexTab?

If you know a tune by its pitches, you can write it in VexTab using note names. If you know it by where your fingers go on the guitar, you can enter the strings and frets instead. VexTab can draw both parts from the same music, so a guitarist reading tab can follow along with someone reading the staff.

You can edit the music directly below each score. The first six lessons take you from a single pitch to reading rhythm in tablature, and in lesson seven you’ll add a player so you can hear the phrases you write. You can also follow the tutorial in the interactive user guide.

Step 1: Your first notes

The first bar begins on middle C, which VexTab writes as C4. Here the author has written Cn4 to show a natural sign beside C. Each pitch gets one beat because a new voice starts in quarter notes, and the vertical bar after F#5 marks the end of the measure.

staff { Cn4 D4 E4 F#5 | }

Try bringing the last note closer to the first three by changing F#5 to F#4. The sharp stays beside F as the note moves down an octave. You can spell other accidentals the same way, putting the sign between the letter and the octave as in Gb4, Gbb4, G#4 or G##4.

On guitar, you can describe where to play each note by giving its fret and string. The next phrase starts at 4/3, the fourth fret of the third string, counting the strings from the high E. Since the first three notes all lie on that string, you can replace 4/3 5/3 6/3 with 4-5-6/3 and still see a separate fret for each beat.

guitar { 4/3 5/3 6/3 10/4 | }

Look at the notes above those frets and you’ll see how VexTab presents a guitar part by default. The next example uses view tab to show the same phrase as tablature alone. Change it to view notation to read the pitches on the staff, then to view both to match each note to the fret beneath it.

guitar { view tab 4-5-6/3 10/4 | }

When you’re sketching a tune, you may know where to put your first finger before you know how the bar will end. Type 4/3 between the inner braces below. The fragment block lets VexTab draw that single fret while you work out the rest of the phrase.

guitar { view tab fragment {} }

Step 2: Note durations

Both bars below take four beats to play, but the melody moves at a different pace in each. Count one beat each for C, D, E and F in the first bar, then hold C for two beats and E for two in the second. You only need to write :q once for the four quarter notes because each pitch takes the current duration until :h changes it to a half note.

meter 4/4 staff { :q C4 D4 E4 F4 | :h C4 E4 | }

To hear where the second note would enter, tap four beats while reading :h C4 E4 and say “E” on beat three. Now change the second bar to :h. C4 :q E4. The dot adds half the value of the half note, so C lasts three beats and E enters on beat four.

You can also give the whole bar to C with :w C4, or divide a single beat into two eighth notes with :8 C4 D4. Four sixteenths, written :16 C4 D4 E4 F4, fit into that same beat.

Step 3: Add some chords

The opening chord and the three notes that follow it use the same pitches, C, E and G. Putting the first three pitches in parentheses tells the player to sound them together on beat one. You can see the difference on the staff, where the three noteheads of the chord share a stem and the following notes each have a stem of their own.

staff { (C4 E4 G4) C4 E4 G4 | }

Try changing E4 to Eb4 inside the parentheses. You’ve changed the opening chord from C major to C minor, while the E on beat three still belongs to the original C-major arpeggio.

The same parentheses work when you write the music in frets. In the tab below, the three zeros stacked above one another tell you to pluck the open strings together. Reading from left to right after the chord, you play those same strings one at a time.

guitar { (0/3 0/2 0/1) 0/3 0/2 0/1 | }

Step 4: Rests and barlines

Count through the first bar as if you were playing it on guitar. Your fingers move up the third string for three beats, then you leave beat four silent before starting the next bar. Since rest takes the same duration as the preceding quarter notes, the bar is complete even though you’ve played only three notes.

guitar { 4/3 5/3 6/3 rest | 5/3 4/3 2/3 2/2 | }

A barline can also tell a player where to go next. In the score below, repeatStart and bar repeatEnd enclose the first bar, including the rest on beat four. The line 0 setting positions that rest on the staff without changing how long the player waits.

staff { repeatStart C4 D4 E4 rest[line 0] bar repeatEnd break system C4 D4 E4 rest bar repeatBoth C4 D4 E4 F4 bar final }

On the second row, the dots on either side of bar repeatBoth mark the end of one repeated passage and the beginning of another. Try replacing bar final with bar double at the end of the piece and compare the thickness of the two lines at the right edge.

Step 5: Tuplets

Suppose you want to play C, D and E evenly on beat one and arrive at F on beat two. In 4/4 there is room for two ordinary eighth notes per beat, so you need a triplet to fit all three pitches there. The ratio in tuplet 3:2 tells VexTab to give the three eighths inside the braces the time that two would usually take.

meter 4/4 staff { tuplet 3:2 { :8 C4 D4 E4 } :q F4 :h G4 | }

Count “one-trip-let” under the first beam, then say “two” when you reach F. If you remove tuplet 3:2 and its braces but leave the notes in place, the editor reports that the bar is too long. Those three eighths would now take a beat and a half, so restoring the triplet brings F back to beat two.

In the guitar phrase below, the slide from fret five through seven to eight fits that same triplet rhythm. Follow it to the two-note chord on beat two, then look at the last beat, where a dotted eighth and a sixteenth fill the space in a different way.

meter 4/4 guitar { key Ab tuning eb :8 tuplet 3:2 { 5/5 7/5[slide] 8/5[slide] } :q (5/2 6/3) 7/3[hammer] :8. 5/4 :16 5/5 | }

Step 6: Give tablature stems

When a guitar part shows both notation and tab, you can read the rhythm from the staff and use the frets to find your place on the instrument. If the guitarist will be reading tab alone, add tabStems on alongside view tab so the tab itself shows which notes share a beam and how long to hold them.

guitar { view tab tabStems on tabDirection up key A fragment { :8 tuplet 3:2 { 5/5 5/4 5/3 } :16 5/1 6/1 7/1 8/1 :8 9/1 10/1[slide] :h 9/1[slide, vibrato] } }

Find the triplet beam above the three opening frets, then change tabDirection up to tabDirection down. The beam now runs below the strings, but it still joins the same three frets. Farther along, the four sixteenths on the first string form a quicker run before the slides into the final half note.

Step 7: Enable and configure the player

To hear the phrase you’ve written, add play { tempo 96 instrument 24 } on a new line above meter in the editor below. When you move the pointer over the score or reach the controls with the Tab key, you’ll find a Play button. Press it and follow the four frets as they sound on nylon-string guitar at 96 quarter notes per minute.

meter 4/4 guitar { :q 0/1 2/1 3/1 2/1 | }

The next example has the same four notes and already includes a player. Compare its controls with the ones you just enabled. The setting controlSize mini selects the small panel, and controls always keeps it in view when you move the pointer away.

play { tempo 96 instrument 24 controls always controlSize mini } meter 4/4 guitar { :q 0/1 2/1 3/1 2/1 | }

If the phrase goes by too quickly to follow the frets, change tempo 96 to tempo 72 and play it again. Once the pace feels comfortable, try instrument 40 in place of instrument 24 to hear a violin play the same notes at the tempo you chose.

For a longer score, you might prefer the larger panel in the upper right, where it can leave the music in view while you read. Try controlSize large position top-right controls hover in place of controls always controlSize mini, then move the pointer away and watch the panel fade. Removing the entire play block takes the controls off this score.

Step 8: Hammer-ons, pull-offs, taps and slides

A guitarist can sound a second note on the same string by hammering a finger onto a higher fret or by pulling a finger off to sound a lower one. In the opening figure, follow 5/3 to 6/3[h]. The mark sits on fret six because that’s where the hammer-on lands.

play { tempo 96 instrument 24 } alias h="hammer" p="pull" gl="slide" v="vibrato" guitar { view tab fragment { :16 (5/2 5/3 7/4) 5/3 6/3[h] 7/4 | 12/4[tap] 7/4[p] 5/4[p] 7/4[h] 7/5 5/5 3/5[gl] | break system (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[bend +1 rise=1] 5/3[bend +1 rise=1])[v] 7/4 0/4[gl] | (5/2 6/3 7/4)[v] | break system (5/4 5/5) (7/4[gl] 7/5[gl]) (5/4[gl] 5/5[gl]) (5/4 5/5) 7/5[h] | (12/5 12/4)[tap] (5/5[gl] 5/4[gl]) 3/5[bend +1 rise=1] 5/6[vibrato wide] } }

Press Play and follow the fourth string just after the first barline. The guitarist taps fret twelve, pulls off to seven and then to five, and hammers back up to seven. The aliases above the part give those gestures short names, so you can read the two [p] marks and the [h] beside their destination frets.

The opening :16 carries through the fragment, giving you four sixteenths per beat. If the changes pass too quickly, slow tempo 96 to tempo 72 and listen again, this time following the line onto string five, where 3/5[gl] marks the end of the slide from fret five to three.

Step 9: Stave keywords

Both notes in this phrase lie on the low sixth string, where the bass clef makes their pitches easy to read. At the start of the staff you can also see the four flats of A-flat major and the cut-time sign, which come from key Ab and meter cut. Change clef bass to clef treble and compare the positions of the two notes with their frets in the tab below.

guitar { meter cut clef bass key Ab fragment { 4/6 5/6 } }

To change what a fret sounds like, choose a tuning for the part. Add tuning dropD before fragment in the guitar block and look at the pitches above frets four and five. Lowering the open sixth string from E to D lowers both notes by a whole tone.

Alongside standard, dropD and eb, VexTab accepts a list of open pitches from the highest string to the lowest, such as tuning (E5 B4 G4 D4 A3 E3). The other staff settings follow the same pattern. You can choose an alto or tenor clef, a minor key such as key F#m, or a meter written as a fraction or a sign such as meter common.

Step 10: Bend a few notes

On the third beat of the opening bar, pick fret six on string three and bend the pitch up one semitone. The bend follows 4-5-6/3, so it belongs to the last fret in that run. With rise=1/1 you have the whole quarter note to reach the top of the bend.

guitar { view tab :q 4-5-6/3[bend +1 rise=1/1] 10/4 | 5/3 4/3 2/3 2/2 | break system 6/3 7/3[bend +2 rise=1/2 release=1] 7/4 rest | 9-8-7-6/2 | }

Compare the bend on the second row, where bend +2 takes the pitch up a whole tone. This time rise=1/2 puts the top of the bend halfway through the note, leaving time to release the string before the next attack.

To bend just one string of a chord, put the mark beside its fret inside the parentheses. In the first chord below, the player holds fret eight on string two while the note on string three bends and releases. In the next chord, both frets carry the bendup mark, so both strings rise together.

alias bendup="bend +1 rise=1" guitar { tabStems off fragment { (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[bendup] 5/3[bendup]) 7/4 | (5/2 6/3 7/4) } }

Here’s how those bends fit into a longer phrase. Count a quarter note for each of the two opening chords, then follow the run on string four. By the time the guitarist taps fret nine, the duration has changed to a sixteenth, leaving room for the slide that follows.

alias gl="slide" half="bend +1 rise=1" guitar { fragment { :q (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[half] 5/3[half])[vibrato] :8 7/4 12/4[gl] :16 9/4[tap] :8 3/4[gl] :16 0/4[gl] } }

Step 11: Mutes, strokes and vibrato

Read the second bar as a sequence of picking strokes. After a downstroke and an upstroke on fretted notes, the pick strikes a muted third string, which appears as x/3 in the source. The final note rings with vibrato, marked by the wavy line at fret two on the second string.

# Aliases alias v="vibrato" alias su="stroke up" sd="stroke down" # Create a guitar stave guitar { 4/3 5/3 6/3[bend +1 rise=1, v] 10/1 | 5/3[sd] 4/3[su] x/3[sd] 2/2[v] | }

The alias lines above the part give the strokes and vibrato short names so you can mark a fret without interrupting the run of notes. In x/3[sd], for example, sd stands for stroke down. Change the definition of v to "vibrato wide" and compare the wavy lines in both bars, since both notes use that alias. The lines beginning with # are comments for the person reading the source.

Step 12: Lyrics and annotations

To put a word exactly where a musician needs it, attach a label to the note where it belongs. In the first example, “Fi”, “Ga” and “Ro!” each follow one note of the triplet, so you can sing a syllable with each pitch. Change below to above on “Fi” and look for the syllable that moves across the staff.

meter 4/4 guitar { key Ab tuning eb :q tuplet 3:2 { 5/5[label "Fi" below] 5/4[label "Ga" below] 5/3[label "Ro!" below] } :h 4/4[label "Blah!" above] | }

Labels also work for playing instructions. Look for the italic “sweep” at the start of the run in the next example, then replace the word with “dolce” in the source. The instruction changes at the same point in the phrase because its label is still attached to the same fret.

guitar { key A (5/2 5/3 7/4)[label "A7#9" above] 5/3 6/3[hammer] 7/4 | :8 7/4[label "sweep" style italic] 6/3 5/2 3/1[vibrato] :q 7/5[label "P.H." font "Arial" size 10 style bold] :8 3/5 5/5[slide] | }

When you need to show a chord change, symbol lets you give the harmony a name. For sung words, lyric can join two syllables with a hyphen or carry one syllable across several notes. You can see both uses under the melody in the Slow river lead sheet.

Step 13: Staccatos, fermatas and more

Two notes of the same written duration can ask quite different things of a player. The staccato dot under the opening C asks you to release it early, while the fermata over E on the fourth row invites you to hold it beyond its written value. The captions under the notes give you the names of the marks as you read down the page.

meter 3/4 staff { C4[staccato below] E4[articulation "av" below] G4[accent below] | break system B4[articulation "a-" below] C5[articulation "a^" above] rest | break system E5[articulation "a+" above] G5[articulation "ao" above] rest | break system C4[articulation "ah" below] E4[fermata above] G4[articulation "a@u" below] | break system B4[articulation "a|" below] C5[articulation "am" above] rest | text names size 12 line 11 { "Staccato" "Staccatissimo" "Accent" | "Tenuto" "Marcato" skip | "Left hand pizzicato" "Snap pizzicato" skip | "Open" "Fermata" "Inverted fermata" | "Up bow" "Down bow" skip | } }

Try changing staccato below to staccato above on the opening C. The dot moves to the other side of the note, but you still count a quarter-note beat before playing E. Shortening the sound leaves a little silence at the end of that beat.

Step 14: Timed text and musical symbols

The guitar plays four notes in the first bar below, but the harmony changes only once, from G minor to A major. To give the chord names their own rhythm, write them in a separate line of text called a lane. In text harmony, each name lasts a half note, which puts “A Major” on beat three with the sustained guitar note.

meter 4/4 guitar { key Ab tuning eb :q tuplet 3:2 { 5/5 5/4 5/3 } :h 4/4 | text harmony line 10 { :h "G Minor" "A Major" | } }

A lane can also move at the same pace as the melody. In the rising scale below, the notes and the syllables are both written in eighths, so “Do” starts on C and “Re” lines up with D.

staff { key Ab :8 C4 D4 E4 F4 G4 A4 B4 C5 | text syllables line 10 { :8 "Do" "Re" "Mi" "Fa" "Sol" "La" "Ti" "Do" | } }

When the page needs both chords and words, give each its own lane and use line to set its height. Higher line numbers sit farther down the page, which is why the chord names below sit above the staff while the sentence runs underneath it. Try replacing "Em" with skip. The lane still counts that half bar, so “G7” arrives on the first beat of the next bar.

staff { C4 D4 E4 F4 | G4 A4 B4 C5 | text chords line -1 { :h "C" "Em" | "G7" "C" | } text words line 11 { :w "This is a new text line." | skip | } }

Use align left, align center or align right when you want to position words around their beat. A sign at a barline needs a different sort of placement. In the last example, start sign coda anchors the coda sign at the opening edge of the bar and end sign segno puts the segno at the closing edge.

staff { repeatStart C4 D4 E4 F4 bar repeatEnd G4 A4 B4 C5 | text road line -2 { start sign coda :h. skip :q sign tr end sign segno | :w skip | } text volume line 9 { :w sign f | skip | } text words line 13 { :w skip | :h skip "D.S. al coda" | } }

Step 15: Write rhythms with slash notation

On a rhythm chart the chord name tells a guitarist what to play, while the slashes underneath tell them when to strum. Under “G Maj7” the first stroke lasts two beats, the next lasts one, and the rest leaves beat four silent. When the chord changes to Am, the first two eighths carry opposite stroke marks so the guitarist can follow the picking direction as well as the rhythm.

staff { clef percussion :h B4[slash, stroke down] :q B4[slash] rest | :8 B4[slash, stroke down] B4[slash, stroke up] :q tuplet 3:2 { B4[slash] B4[slash] B4[slash] } :q slash | text harmony line -2 { :w "G Maj7" | "Am" | } }

Look at the end of the Am bar, where :q slash supplies an unpitched quarter-note beat. Earlier in the bar, B4[slash] places a slash head at a particular staff position, as in the downstroke and upstroke that open the bar.

Step 16: Customize the appearance

If you’re preparing a lesson about a single note, enlarging the staff gives your reader room to see the head and stem. The first example uses scale 2 to draw the whole score at twice its usual size. Change it to scale 1 and compare the notehead with the distance between staff lines as both return to their usual size.

layout { width 200 scale 2 } guitar { view notation fragment { :q 5/5 } }

For a phrase that reaches high up the neck, look at the space above the notation as well as the tab below it. In the next example, the chord name sits above the opening chord, while the three high notes need room for their ledger lines. You can follow the same rise in the tab from fret fifteen to fret twenty on the first string.

guitar { key A (5/2 5/3 7/4)[label "A7#9" above] 15/1 16/1[hammer] 20/1 | }

Low notes need room on the other side of the staff. In the last example, find the open sixth string in the tab and trace it up to the ledger lines below the notation. Try increasing staffDistance 50 to give those lines more clearance above the tab. When you want more space between successive rows of music, use rowGap to separate the systems. Set width in pixels to choose how much room each system has across the page.

layout { staffDistance 50 scale 0.8 } guitar { key A fragment { (5/2 5/3 7/4) rest 0/6 1/6[hammer] 0/1 } }
