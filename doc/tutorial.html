The VexTab Tutorial

Fourteen steps to writing notation and guitar tablature with VexTab

What is VexTab?

VexTab is a language that allows you to easily create, edit, and share standard notation and guitar tablature. Unlike ASCII tab, which is designed for readability, VexTab is designed for writeability.

Follow the steps below to start writing music. The source boxes are editable. You can also read this tutorial in the VexTab 5 user guide.

Step 1: Your first notes

Play these four quarter notes. Write a letter and octave for each pitch, and close the bar with |. Change the last pitch and play it again.

staff { Cn4 D4 E4 F#5 | }

On guitar, write fret/string. String one is the high E. Try these four notes, then shorten the first three positions to 4-5-6/3. Each fret gets its own beat.

guitar { 4/3 5/3 6/3 10/4 | }

Guitar shows both staves by default. Choose view tab for tablature alone, view notation for the staff alone, or view both to see them together.

guitar { view tab 4-5-6/3 10/4 | }

An empty fragment draws the staff without notes. Add a fret inside the inner braces to start a sketch.

guitar { view tab fragment {} }

For a named pitch, try Gb4, Gbb4, G#4, G##4 and Gn4. Put the accidental between the letter and octave.

Step 2: Stave keywords

Set the meter inside the part alongside its clef, key and tuning. Here the low sixth string is shown in bass clef with an A-flat signature and cut time.

Choose view tab, view notation or view both. Common clefs include treble, alto, tenor and bass. Major and minor key names include Ab and F#m. Guitar tunings include standard, dropD, eb and an explicit list from the highest string down, such as tuning (E5 B4 G4 D4 A3 E3). Use meter common, meter cut or a fraction.

guitar { meter cut clef bass key Ab fragment { 4/6 5/6 } }

Step 3: Rests and barlines

A rest takes the current duration. Place its head with rest[line 0]. A vertical bar closes a measure. Use repeatStart, bar repeatEnd, bar repeatBoth and bar final to draw repeat boundaries.

Try bar double for a double bar. Use break system at the beginning of a bar to start a staff row.

guitar { 4/3 5/3 6/3 rest | 5/3 4/3 2/3 2/2 | }
staff { repeatStart C4 D4 E4 rest[line 0] bar repeatEnd break system C4 D4 E4 rest bar repeatBoth C4 D4 E4 F4 bar final }

Step 4: Bend a few notes

Attach a bend to the picked fret. The amount is in semitones. The rise, hold and release fractions locate the phases within that note. The destination stays on the same string.

guitar { view tab :q 4-5-6/3[bend +1 rise=1/1] 10/4 | 5/3 4/3 2/3 2/2 | break system 6/3 7/3[bend +2 rise=1/2 release=1] 7/4 rest | 9-8-7-6/2 | }

Step 5: Mutes, strokes and vibrato

Give frequently used marks short names with alias. Here [v] adds vibrato and [sd] marks a downstroke. One declaration can name several marks. Change the definition of v to "vibrato wide" to change both attacks. Lines beginning with # are comments.

# Aliases alias v="vibrato" alias su="stroke up" sd="stroke down" # Create a guitar stave guitar { 4/3 5/3 6/3[bend +1 rise=1, v] 10/1 | 5/3[sd] 4/3[su] x/3[sd] 2/2[v] | }

Step 6: Add some chords

Parentheses group notes that sound together. A mark inside the parentheses belongs to that chord member. Compare a C-major triad with its arpeggio, then try the independently bent strings.

staff { (C4 E4 G4) C4 E4 G4 | }

Here the bass stays steady while one or two other strings bend. Read each bend next to its own fret.

alias bendup="bend +1 rise=1" guitar { tabStems off fragment { (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[bendup] 5/3[bendup]) 7/4 | (5/2 6/3 7/4) } }

Step 7: Hammer-ons, pull-offs, taps and slides

A hammer, pull or slide joins a head to the preceding attack on the same string. A tap starts a new attack. Listen to the tap at fret twelve and follow the pull-offs.

alias h="hammer" p="pull" gl="slide" v="vibrato" guitar { view tab fragment { :q (5/2 5/3 7/4) 5/3 6/3[h] 7/4 | 12/4[tap] 7/4[p] 5/4[p] 7/4[h] 7/5 5/5 3/5[gl] | break system (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[bend +1 rise=1] 5/3[bend +1 rise=1])[v] 7/4 0/4[gl] | (5/2 6/3 7/4)[v] | break system (5/4 5/5) (7/4[gl] 7/5[gl]) (5/4[gl] 5/5[gl]) (5/4 5/5) 7/5[h] | (12/5 12/4)[tap] (5/5[gl] 5/4[gl]) 3/5[bend +1 rise=1] 5/6[vibrato wide] } }

Step 8: Durations and tuplets

Use :q, :h, :8 and :16 for quarter, half, eighth and sixteenth notes. A dot adds half the written duration. A tuplet 3:2 block fits three written eighths into the time of two. Change a duration inside the block to hear its effect.

A voice starts with quarter notes. :w selects whole notes, :32 thirty-seconds and :q. dotted quarters. Set a duration inside a tuplet for a mixed group. The enclosing duration resumes after its closing brace.

meter 4/4 guitar { key Ab tuning eb :8 tuplet 3:2 { 5/5 7/5[slide] 8/5[slide] } :q (5/2 6/3) 7/3[hammer] :8. 5/4 :16 5/5 | }
alias gl="slide" half="bend +1 rise=1" guitar { fragment { :q (8/2 7/3[bend +2 rise=1/2 release=1]) (5/2[half] 5/3[half])[vibrato] :8 7/4 12/4[gl] :16 9/4[tap] :8 3/4[gl] :16 0/4[gl] } }

Step 9: Lyrics and annotations

Attach a syllable, chord name or instruction to its attack with a text label. For hyphens and extenders, use a lyric mark as in the lead-sheet study. A label can set a font, size, style, colour and position. In the first example, each triplet note gets its own syllable.

Try [label "dolce" below font "Times New Roman" size 14 style italic ink navy]. A symbol supplies a chord name. A lyric can carry a hyphen or extend over subsequent attacks.

meter 4/4 guitar { key Ab tuning eb :q tuplet 3:2 { 5/5[label "Fi" below] 5/4[label "Ga" below] 5/3[label "Ro!" below] } :h 4/4[label "Blah!" above] | }
guitar { key A (5/2 5/3 7/4)[label "A7#9" above] 5/3 6/3[hammer] 7/4 | :8 7/4[label "sweep" style italic] 6/3 5/2 3/1[vibrato] :q 7/5[label "P.H." font "Arial" size 10 style bold] :8 3/5 5/5[slide] | }

Step 10: Staccatos, fermatas and more

Place an articulation on a head. Choose above or below to position the mark. The text under each attack names the symbol. Try staccato and fermata before exploring the other VexFlow articulation codes.

meter 3/4 staff { C4[staccato below] E4[articulation "av" below] G4[accent below] | break system B4[articulation "a-" below] C5[articulation "a^" above] rest | break system E5[articulation "a+" above] G5[articulation "ao" above] rest | break system C4[articulation "ah" below] E4[fermata above] G4[articulation "a@u" below] | break system B4[articulation "a|" below] C5[articulation "am" above] rest | text names size 12 line 11 { "Staccato" "Staccatissimo" "Accent" | "Tenuto" "Marcato" skip | "Left hand pizzicato" "Snap pizzicato" skip | "Open" "Fermata" "Inverted fermata" | "Up bow" "Down bow" skip | } }

Step 11: Timed text and musical symbols

Give text a named lane with its own durations. It can move while the instrumental note is held. Use line to set its height, skip to reserve silent time, and start or end to put a sign on a bar boundary.

Multiple lanes have independent clocks. Higher line numbers move the lane down. Choose align left, align center or align right for the words. A quoted comma remains part of the text. A sign uses the score’s music font.

meter 4/4 guitar { key Ab tuning eb :q tuplet 3:2 { 5/5 5/4 5/3 } :h 4/4 | text harmony line 10 { :h "G Minor" "A Major" | } }
staff { key Ab :8 C4 D4 E4 F4 G4 A4 B4 C5 | text syllables line 10 { :8 "Do" "Re" "Mi" "Fa" "Sol" "La" "Ti" "Do" | } }
staff { C4 D4 E4 F4 | G4 A4 B4 C5 | text chords line -1 { :h "C" "Em" | "G7" "C" | } text words line 11 { :w "This is a new text line." | skip | } }
staff { repeatStart C4 D4 E4 F4 bar repeatEnd G4 A4 B4 C5 | text road line -2 { start sign coda :h. skip :q sign tr end sign segno | :w skip | } text volume line 9 { :w sign f | skip | } text words line 13 { :w skip | :h skip "D.S. al coda" | } }

Step 12: Write rhythms with slash notation

Use slash for an unpitched beat or put [slash] on a written pitch. It follows the same rhythm rules as a note. The timed harmony line changes once per bar.

staff { clef percussion :h B4[slash, stroke down] :q B4[slash] rest | :8 B4[slash, stroke down] B4[slash, stroke up] :q tuplet 3:2 { B4[slash] B4[slash] B4[slash] } :q slash | text harmony line -2 { :w "G Maj7" | "Am" | } }

Step 13: Customize the appearance

Use the layout block to set a width, scale or distance between paired staves. Compare a single enlarged note, a labelled high-register chord exercise and a phrase on the low sixth string.

Widths and staff distances are in pixels. Scale 1 is the original size. Choose rowGap between systems and staffDistance between notation and tab. Put font, size and style on the label or text lane.

layout { width 200 scale 2 } guitar { view notation fragment { :q 5/5 } }
guitar { key A (5/2 5/3 7/4)[label "A7#9" above] 15/1 16/1[hammer] 20/1 | }
layout { staffDistance 50 scale 0.8 } guitar { key A fragment { (5/2 5/3 7/4) rest 0/6 1/6[hammer] 0/1 } }

Step 14: Give tablature stems

Choose view tab and enable tabStems to show rhythm on tablature alone. The first three frets are an eighth-note triplet. Follow the shorter run and slides into the final vibrato.

Use tabDirection up or tabDirection down to set the stems. Try changing the direction before playing the phrase.

guitar { view tab tabStems on tabDirection up key A fragment { :8 tuplet 3:2 { 5/5 5/4 5/3 } :16 5/1 6/1 7/1 8/1 :8 9/1 10/1[slide] :h 9/1[slide, vibrato] } }
