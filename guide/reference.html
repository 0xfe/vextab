Modules and entry points

vextab/parse

DOM-free entry point for Node, workers and validators. Exports parseScore, ScoreError and the TypeScript types ParsedScore and SourceRange. CommonJS and ES modules are supported.

import { parseScore } from 'vextab/parse';
const score = parseScore('meter 1/4 staff { C4 | }', { language: 2 });

vextab/browser

Use this entry for explicit mounting in a browser application. It exports the parser, Div, renderScore, renderScorePart, the Part type, the playback adapters createWebAudioPlayback and createSpessaSynthPlayback, and Artist, VexTab, Player and Vex objects.

import { Div, parseScore, renderScore } from 'vextab/browser';

vextab/auto and script tags

The auto entry mounts each div.vextab-auto on DOM ready. Load dist/div.prod.js for a plain HTML page. The package root and dist/main.prod.js retain the legacy browser API. The old dist/vextab-div.js adapter supports .vex-tabdiv, underscore editor attributes and the original Canvas default.

<div class="vextab-auto" data-language="2" editor="true">guitar { 0/1 2/1 3/1 2/1 | }</div>
<script src="./div.prod.js"></script>

Parsing and the score model

parseScore(source, { language: 2 })

Parse a score once, then pass it to the renderer, printer or player. The returned ScoreV2 retains the original source and the expanded music. Use fragment { … } for an incomplete phrase.

transpose

Write a signed semitone offset before the first stave. Both the printed signature and the sounding notes move. Guitar notes stay on their original strings. Change the source fingering if a downward shift would require a negative fret.

transpose +2
meter 4/4
guitar { key C :q 3/5 5/5 7/5 8/5 | }

This shifts C major to D major and displays frets 5, 7, 9, and 10 on string five.

Grammar v2 preview

Pass { language: 2 } as the second argument to parseScore to read the new grammar. The returned ScoreV2 contains the authored source, parts, staves, named voices, measures and timed events. For example, parseScore('staff { :w C4 | }', { language: 2 }).measureCount is 1. Pass that score to renderScore, renderScorePart, or Player. Add data-language="2" to try v2 in an editable embed. Use ScoreV2Error.range to select invalid input in an editor. Calls without the option continue to return the current ParsedScore.

ScoreV2

A part contains staves and named voices. Each voice has ordered events and a list of measures indexing them. An event has its exact onset, duration, heads and source range.

const event = score.parts[0].staves[0].voices[0].events[0];
const token = score.source.slice(...event.range);

ScoreV2Error and source ranges

Grammar errors report a one-based line and column. The range contains two UTF-16 offsets into the original input. The end is exclusive.

try { parseScore(input.value, { language: 2 }); }
catch (error) {
  if (!(error instanceof ScoreV2Error)) throw error;
  input.focus();
  input.setSelectionRange(...error.range);
}

Rendering and navigation

renderScore(host, score, options?)

Engrave a parsed score into an HTML element using SVG. width takes CSS pixels and must exceed 20. It defaults to the host width or 640 if the host has no width. part accepts 'score' (all authored staves), 'notation' or 'tab'. The host is replaced after successful layout. The returned view contains the composition, navigation, hit regions and diagnostics.

const score = parseScore(input.value, { language: 2 });
const view = renderScore(preview, score, { width: 640, part: 'tab' });

navigation.events and hitTest(x, y)

Read view.navigation.events in musical order. Each entry has a label and projected ID. view.hitTest(x, y) takes SVG-local coordinates and returns a hit region or undefined. Convert pointer positions with the SVG screen transform when scaling the preview. A wrapped tie may have several regions.

sourceFor(id) and rangeFor(id, source)

Screen and print views can have different projected IDs for the same written attack. sourceFor resolves the projection to its musical ID. rangeFor returns a source range for a matching source string. Unrecognized IDs and stale source produce undefined.

const range = view.rangeFor(view.navigation.events[0].id, input.value);
if (range) input.setSelectionRange(range.start, range.end);

DOM embeds and live editors

new Div(host)

Pass an HTML element or a selector for one host. The constructor reads its text and attributes, renders immediately, and optionally adds an editor. Set textContent for source supplied by a user. Use one instance per host.

import { Div } from 'vextab/browser';
host.setAttribute('layout', 'flow');
host.setAttribute('editor', 'true');
host.textContent = 'meter 1/4 staff { C4 | }';
const editor = new Div(host, { language: 2 });

Host attributes and defaults

Each setting accepts a data- prefix. For example, set data-layout="flow" data-editor="true" data-width="auto" for a responsive editor. A nonempty prefixed value takes precedence over the plain attribute.

layout, renderer, scale
Fixed layout defaults to SVG at scale 1 and also supports Canvas. Flow uses layout="flow" with SVG at scale 1.
width
Fixed defaults to 400 px. A flow host with an omitted width or width="auto" follows its container.
editor, show-errors
Set editor="true" to expose the source textarea. show-errors="true" displays diagnostics without the editor.
editor-width, editor-height
Pixel dimensions. Defaults are the score width and 200 px high. The historical adapter also accepts editor_width and editor_height.

run(), redraw(), parse() and draw()

run() flushes the pending edit and draws the current textarea value. Keyboard users can press Ctrl+Enter or Command+Enter. redraw() reparses the stored source and draws it. parse() and draw() expose the two stages. These methods return the instance. A failing edit keeps the last valid picture and displays the error.

setPart(part) and setWidth(pixels)

Flow-only methods that return the editor. Select a staff or reflow the same parsed revision without rewriting the source. Setting a width explicitly takes over from automatic container observation.

getScore(), getReadingEvents() and selectSource()

getScore() returns the current valid flow revision or undefined. getReadingEvents() returns the current reading order, or an empty array when unavailable. selectSource(id, revision) focuses the editor and selects the matching token. It returns false for a stale revision or missing selection.

const revision = editor.getScore();
const [first] = editor.getReadingEvents();
if (revision && first) editor.selectSource(first.id, revision);

getDiagnosticRange() and selectError()

Read the located error in the current edit or select its characters. getDiagnosticRange() returns undefined for a valid score or an obsolete diagnostic. selectError() returns whether the editor could select the range.

vextab-render and dispose()

Listen for vextab-render on the host to refresh controls after an engraving attempt. Call editor.dispose() before unmounting. It disconnects resize observation and cancels pending editor work. The host application owns its DOM and its own event listeners.

Publication and export

renderScorePart(host, score, staff, options?)

Independently engrave 'notation' or 'tab' from the same parsed score. Omit voice to retain every voice on that staff, or pass a one-based voice number. Choose paper: 'A4' or 'Letter' and set a title. The result includes the selected score, its publication, sourceFor and rangeFor.

const { publication } = renderScorePart(paperHost, score, 'notation', {
  voice: 2, title: 'Guitar 2', paper: 'Letter'
});

PublicationResult.pages, diagnostics and toPrintHTML()

Each page has an SVG and its musical metadata. Inspect publication.diagnostics for overflow and engraving details. Supply matching outline fonts to toPrintHTML(faces) for an offline print document or toSVG(pageNumber, faces) for a single outlined page. Page numbers start at one. The guide supplies Bravura and Academico.

Piano grand staff and hand parts

Put upper { … } and lower { … } inside a piano part. Both hands share the meter, keys and bar boundaries. A hand can contain several named voices. Set stem up and stem down for opposing stems.

Use layout="flow" for an SVG embed. Modern and legacy embeds initially containing a piano declaration also select flow automatically. For a programmatic score, pass parseScore(source, { language: 2 }) to renderScore or Player. Pass part: 'left' or 'right' to show one hand. The reader and playback follow the visible hand in an embed.

renderScorePart(host, score, 'notation') prints both staves. Use 'right' or 'left' for a practice part. The optional voice number selects one voice within that hand. Native part engraving limits also apply to piano. Try two-hand and four-voice examples.

Independent part coverage

Parts preserve augmentation dots, tab ties, repeat boundaries, chord names and notation lyrics. Some marks still need the screen pass, including chord frames, silent positions and explicit written accidentals in single-stave notation parts. Piano parts preserve explicit and cautionary accidentals on each hand. A located error identifies the unsupported mark. Selecting a voice missing from a bar also produces an error.

Rendering a fragment

Free-form examples

Put an unfinished bar inside a fragment block. Set the host width to keep a fixed-width example.

Render into SVG or Canvas

const score = parseScore('guitar { fragment { 3/2 5/2 } }', { language: 2 });
renderScore(host, score, { width: 500, renderer: 'canvas' });

Change the view

Pass the same score back to renderScore when the available width changes. A Div editor can use setWidth directly.

Playback and instruments

Player, tempo and instrument

Pass a ScoreV2 to new Player(source, options). Call play() from a user gesture. Its promise resolves at the end or on Stop and rejects on audio errors. stop() cancels a pending load and releases sounding notes. dispose() also removes controls. setTempo(bpm) changes the tempo during playback. setInstrument(program) stops the current performance.

In an embed, put play { tempo 96 instrument 24 } before the first stave. Tempo defaults to 120 quarter notes per minute. Instrument accepts a General MIDI program from 0 to 127 or a supported name such as acoustic_guitar_nylon. Use the metronome beside Play to adjust playback tempo. Play a phrase →

createWebAudioPlayback() and createSpessaSynthPlayback(synth, channels?)

Embeds default to a sample-free Web Audio instrument. For a SoundFont host, load the matching worklet and bank, connect the synth to your output, then pass the adapter to the editor. A reserved channel pool lets a bent string change pitch independently of its neighbours. Set up SpessaSynth and play a SoundFont →

const playback = createSpessaSynthPlayback(synth);
const editor = new Div(scoreHost, { language: 2, playback, player: true });

player: true enables the sheet controls even for source without a player directive. Custom instruments implement PlaybackPlugin.open(program, signal) and return a session with playNote(note) and stop().

Pre-bent attacks
