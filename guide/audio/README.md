# Guide instrument bank

The guide uses Nando Florestan’s public-domain SoundFont subset. Its SF2 INFO record lists “Public Domain” under ICOP. The nylon-string guitar is General MIDI program 24 and the piano is program 2. [Original bank in TinySoundFont](https://github.com/schellingb/TinySoundFont/blob/a3621a19c6504885cd9583e6e26c35bc954fc8ec/examples/florestan-subset.sf2)
