Measures, pickups and reflow

A pickup begins a piece before its first full downbeat. Give that opening bar its own length so it still counts correctly when the score wraps.

Count one beat for the opening G, then three for A, B and C. The score declares pickup 1/4 in a meter of 3/4. Delete C from the second bar and the editor reports the missing beat. Restore C to complete the bar. For a sketch whose length you want to leave open, use fragment { … }.

meter 3/4
pickup 1/4
staff {
  :q G4 |
  :q A5 B5 C5 |
  :h D5 :q B4 |
}

Give each staff its own meter

Follow the first six beats in each part. The staff divides them into four plus two, while the guitar divides them into three plus three. Both arrive at the end together even though their first barlines fall a beat apart.

staff { meter 4/4 C4 D4 E4 F4 |
  meter 2/4 G4 A4 | }
guitar { meter 3/4 0-2-3/1 | 3-2-0/1 | }

Beam groups and accidental spelling

A beam shows which short notes a player should read as a group. VexTab can group them from the meter, or you can specify the phrasing yourself.

The first beam joins C, D and E. Move the closing brace past F to put four stems under that beam. The measure still has six eighth notes. The flat on the final B comes from Bb4, and [courtesy] requests a reminder accidental.

meter 3/4 staff { :8 beam { C4 D4 E4 } F4 beam { A4 Bb4[courtesy] } | }

Play a phrase with a SoundFont

Listen to two bars on nylon-string guitar, then change either the instrument or the performer to hear what each contributes.

Move the pointer over the music or focus the player with the keyboard. Set controls always to leave it visible, or position top-right to move it. The large panel follows the playing system when auto-scroll is on. Its three horizontal lines switch scrolling off. Choose controlSize mini for just the transport and tempo.

play { tempo 96 instrument 24 performer human controls hover }
meter 4/4
guitar {
  :8 0/1 2/1 3/1 2/1 :q 0/1 3/2 |
  :8 1/2 3/2 0/1 2/1 :h 0/1 |
}

Press Play. The first play loads the guide’s SoundFont. Once you hear the phrase, open the metronome and use − or + to change the tempo. Stop, change instrument 24 to instrument 40 and play again. The same notes now sound on violin. Program 12 selects marimba.

Keep the instrument and change performer human to performer robot to hear the written timing and dynamics. When the music changes to a new dynamic, the human performers begin the change on the marked attack and settle into it over the next quarter note. For a different interpretation, try bach for a steady pulse, chopin for a broader phrase, parker for bebop, ragtime for straight syncopation or blues for a shuffle.

Watch the last open string. Its yellow glow lasts through the half note while the gray playhead moves across the bar. A rest leaves time for the playhead to travel, and a tie carries the sound into the next note. To use the guide’s sampled instruments in your own page, follow the SpessaSynth setup. Colour a stave, an attack or a chord label

Colour can draw a student’s eye to one fret while leaving the surrounding strings and chord name legible.

meter 2/4
guitar { view tab ink SeaGreen ink default at 2
  0/1[ink #1565c0, symbol "Em" ink crimson] 2/1 |
  break system 3/1 0/1 |
}

The first string is open on beat one. Change the two attacks to 0/1[symbol "Em" ink crimson] 2/1[ink #1565c0]. The blue moves to beat two while “Em” stays crimson on beat one. The stave returns to its usual colour at bar two because the part specifies ink default at 2. These colours carry through to print. Staff, attack and label ink.

Piano grand staff

Follow the bass while the right hand plays E, G, C and G. The left hand strikes twice, first with E and then with C on beat three. Each hand fills four beats at its own pace.

play { tempo 96 }
meter 4/4
piano {
  upper {
    :q E4 G4 C5 G4 |
    :q F4 A4 C5 A4 |
  }
  lower {
    :h (C3 G3) G2 |
    :h (F2 C3) C3 |
  }
}

A voice is a musical line with its own rhythm. In this second example, the upper staff holds E while G moves to A above it. Put the lines in separate voice blocks and give them opposite stem directions so a pianist can follow each line.

meter 2/4
piano {
  upper {
    voice melody stem up {
      :q G4 A4 |
    }
    voice bass stem down {
      :h E4 |
    }
  }
  lower {
    voice voice3 stem up {
      :h C3 |
    }
    voice voice4 stem down {
      :q F2 G2 |
    }
  }
}

Fingerings and accents

Compare the fingering above the fretted phrase with the accent on the last attack. Change finger 3 right to finger 3 left. The number changes sides while the accent stays with the note.

meter 2/4 guitar { :8 6/4[finger 2] 7/4[hammer, finger 3] :q 0/2[finger 3 right, accent] | }

In the chord below, finger 1 belongs to C and finger 3 to E because each mark follows its own pitch inside the parentheses. Numeric fingerings accept 0 through 5, with T for the thumb. Use left, right, above or below to place the mark.

meter 2/4
staff {
  :q (C4[finger 1 left] E4[finger 3 right]) G4[finger 5 left, accent above] |
}

Compare the paired guitar example with the staff example. Look on the standard staff for the finger numbers and on both guitar staves for the accent. You can also print the named pitches and their markings as an independent notation part.

Independent voices and ties

A singer can hold a note over a barline while the bass changes underneath. Give the melody and bass separate voices so each can keep its own rhythm.

In the melody, the G on beat two continues into bar two. Put [tie] on the second G to tell the player to sustain it. Remove that mark and replay the phrase. You should hear a fresh G as the bass changes from C to D.

meter 2/4
staff {
  voice melody stem up {
    :q E5 G5 |
    :q G5[tie] E5 |
  }
  voice bass stem down {
    :h C4 |
    :h D4 |
  }
}

Bends and palm muting by string

Hold one string steady while its neighbour bends, then mute the two low notes in the following bar.

String two stays at fret five while string three bends up two semitones. It reaches the top halfway through the half note, holds to the three-quarter point and releases by the end. In bar two, palmMute strings(6) confines the mute to the sixth string.

meter 2/4
guitar {
  tuning dropD
  tabStems on
  :h (5/2 7/3[bend +2 rise=1/2 hold=3/4 release=1/1]) |
  palmMute strings(6) { :q 0/6 3/6 } |
}

Open-ended slides

A guitarist can slide into a note without specifying the starting fret. Look at the two approaches to fret nine in bar one. The first rises into the note and the second falls into it. In bar two, the marks show the direction of travel after the attack.

alias approach="slideIn below" leave="slideOut below"
meter 2/4
guitar {
  :q 9/3[approach] 9/3[slideIn above] |
  :q 9/3[leave] (9/3[slideOut above] 7/2) |
}

Each open-ended slide sounds one written fret. To join two particular frets, give both positions and mark the destination. In fixed layout, 5/3 7/3[slide] connects fret five to fret seven.

Pick a pre-bent string and release it

A pre-bend starts at the raised pitch. Listen for the upper note to fall while the open bass underneath it stays level.

play { tempo 80 instrument 24 }
meter 2/4
guitar {
  :q (0/6 7/3[prebend +1 release]) 7/3 |
}

Raise fret seven by one semitone before picking it. The word release lets the string return during that quarter note. Remove it and compare the bent note with the ordinary seventh fret on beat two. Compare a bend that starts after the attack.

Drum kit notation

Read the first bar from the kick in the bottom space to the snare in the third space and the closed hi-hat above the staff. Its cross-shaped head distinguishes the hat. A drums part lets you enter each hit by its kit name.

meter 4/4
drums {
  :q kick snare hat rest |
  :8 (kick hat) hat (snare hat) hat (kick hat) hat (snare hat) hat |
}

In bar two the hat plays every eighth, but only some strokes share a stem with the kick or snare. Parentheses place those hits together. Give the feet and hands separate voices if their durations differ. This example engraves the drum pattern. The player does not synthesize the kit hits.

Chord frames and lyric syllables

A lead sheet can show the chord a guitarist grips and the syllable a singer starts at the same moment.

At “Sail”, read the Am diagram from the low string to the high string. Skip the string marked x, leave 0 open and barre strings four and three at fret two. At “on”, extend=1 carries the syllable across the final C. Remove the extension and compare the end of the lyric line.

meter 4/4
guitar {
  view notation
  :h (0/5 2/4 2/3 1/2 0/1)[symbol "Am", frame (x 0 2 2 1 0) barre=2/4..3, lyric "Sail"] :q E5[lyric "on" extend=1] C5 |
}

Rehearsal marks and repeat endings

Two endings let a player repeat the same opening and leave it by a different route on the second pass.

Start at rehearsal mark A with C and D. On the first pass, play E and D and follow the repeat sign back to A. On the second pass, skip to the held C. The volta 2 block contains the shared music, so you write that opening once.

measureNumbers on
meter 2/4
staff {
  volta 2 {
  mark "A" :q C4 D4 |
  } ending 1 {
  :q E4 D4 bar repeatEnd
  } ending 2 {
  :h C4 bar final
  }
}
