Measures, pickups and reflow

Write a pickup that keeps its length as the music wraps onto a narrower page.

Flow layout counts each voice against the time signature and breaks at barlines. Here the opening G is a one-quarter pickup in 3/4. The next bar has three beats. Delete its last note to see the diagnostic, then restore it. Use fragment { … } for a deliberately incomplete excerpt.

meter 3/4
pickup 1/4
staff {
  :q G4 |
  :q A5 B5 C5 |
  :h D5 :q B4 |
}

Both parts begin together. The guitar plays two bars of 3/4. The first staff plays a bar of 4/4 and changes to 2/4 at the barline. Both finish on the same beat.

staff { meter 4/4 C4 D4 E4 F4 |
  meter 2/4 G4 A4 | }
guitar { meter 3/4 0-2-3/1 | 3-2-0/1 | }

Choose where a group of eighth notes begins and ends, or let the meter decide.

Play a phrase with a SoundFont

Play this two-bar guitar phrase twice. Listen for the slight variation in an otherwise steady pulse.

Edit controls hover to controls always to keep the player visible, or try position top-right to move it. The player follows the visible area as you scroll a long score.

play { tempo 96 instrument 24 performer human controls hover position bottom-center }
meter 4/4
guitar {
  :8 0/1 2/1 3/1 2/1 :q 0/1 3/2 |
  :8 1/2 3/2 0/1 2/1 :h 0/1 |

Piano grand staff

The right hand plays four quarter notes while the left plays two half notes. Play the phrase, then change the bass rhythm without changing the melody. Each hand fills the same bars.

play { tempo 96 }
meter 4/4
piano {
  upper {
    :q E4 G4 C5 G4 |
    :q F4 A4 C5 A4 |
  }
  lower {
    :h (C3 G3) G2 |
    :h (F2 C3) C3 |
  }
}

The upper and lower blocks select the piano hands. Within either hand, give independent lines their own named voices. Set stem up or stem down on each voice.

meter 2/4
piano {
  upper {
    voice melody stem up {
      :q G4 A4 |
    }
    voice bass stem down {
      :h E4 |
    }
  }
  lower {
    voice voice3 stem up {
      :h C3 |
    }
    voice voice4 stem down {
      :q F2 G2 |
    }
  }
}

Fingerings and accents

Attach a finger to a head with [finger 2]. Add accent inside the brackets for an accent. Change finger 3 right to finger 3 left and compare the placement.

meter 2/4 guitar { :8 6/4[finger 2] 7/4[hammer, finger 3] :q 0/2[finger 3 right, accent] | }

Finger numbers run from 0 to 5. Use finger T for thumb. Choose left, right, above or below after the finger. Put the brackets inside a chord to mark that particular head.

meter 2/4
staff {
  :q (C4[finger 1 left] E4[finger 3 right]) G4[finger 5 left, articulation undefined above] |
}

Independent notation parts print marks on named pitches and chords. For marks on fretted notes, use the fixed or flow view. Finger numbers appear on standard notation. Accents also appear on tablature.

Independent voices and ties

Let a melody cross a barline while the bass keeps its own pulse.

Each named voice begins at the first beat. Both voices fill the same bars. Put [tie] on the arriving head to sustain the matching pitch.

    :q E5 G5 |

Bends and palm muting by string

Bend one string of a chord while its neighbor keeps sounding.

The half note stops strings two and three. The bend on string three rises two semitones. Its fractions specify the end of the rise, hold and release. palmMute strings(6) { … } covers the bass phrase in the second bar.

meter 2/4
guitar {
  tuning dropD
  tabStems on
  :h (5/2 7/3[bend +2 rise=1/2 hold=3/4 release=1/1]) |
  palmMute strings(6) { :q 0/6 3/6 } |
}

Open-ended slides

Attach slideIn below or slideIn above to approach the picked note. Use slideOut to leave it. Follow the direction of all four slide marks.

alias approach="slideIn below" leave="slideOut below"
meter 2/4
guitar {
  :q 9/3[approach] 9/3[slideIn above] |
  :q 9/3[leave] (9/3[slideOut above] 7/2) |
}

Each slide has one picked attack. Playback uses its written fret. To slide between two specified frets in fixed layout, use 5/3 7/3[slide].

Drum kit notation

Write a groove with drums { … }. In the first bar, read the kit from low to high. kick is a round head in the bottom space, snare is a round head in the third space, and hat is a cross above the top line for the closed hi-hat.

meter 4/4
drums {
  :q kick snare hat rest |
  :8 (kick hat) hat (snare hat) hat (kick hat) hat (snare hat) hat |
}

Parentheses put both instruments on the same stem. To give the feet and hands independent rhythms, put them in separate voices. Drum hits have no sounding pitch in VexTab playback.

Chord frames and lyric syllables

Give a chord its name, its guitar fingering and a place in a lyric.

Put each mark after its attack. The Am frame lists six strings from low to high. An x skips the sixth string and 0 rings an open string. The barre stops strings four and three at fret two. On the next attack, extend=1 holds “on” through one more note.

meter 4/4
guitar {
  view notation
  :h (0/5 2/4 2/3 1/2 0/1)[symbol "Am", frame (x 0 2 2 1 0) barre=2/4..3, lyric "Sail"] :q E5[lyric "on" extend=1] C5 |
}

Rehearsal marks and repeat endings

Mark where to return and give each pass its own ending.

Use mark "A" at the beginning of a bar. A volta 2 block prints the shared music, followed by its two numbered endings. Measure numbers follow the written score.

measureNumbers on
meter 2/4
staff {
  volta 2 {
  mark "A" :q C4 D4 |
  } ending 1 {
  :q E4 D4 bar repeatEnd
  } ending 2 {
  :h C4 bar final
  }
}
