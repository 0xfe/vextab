Get VexTab on a page

Put an editable guitar part on a plain HTML page. The browser bundle includes VexFlow and the engraving fonts. You need one script and a score written as text.

VexTab 6 reads this notation by default. Save this page as index.html beside the script and open it in your browser.

You should see four quarter notes above the matching frets. Change 3 to 5 and press Ctrl+Enter or Cmd+Enter to redraw. Resize the window to see how the layout follows its container.

VexTab 5 was an experimental release that used grammar v1. For a v1 score, add data-language="1" to its embed or pass { language: 1 } to parseScore. To convert it, follow the migration guide.

In a bundled app, import 'vextab/auto' gives the same automatic mounting behavior. To create an editor when a component mounts, use the JavaScript example.

Embed a score in your code

Use vextab/browser in an app with a JavaScript bundler. Give VexTab an empty element after it enters the DOM. Set its text to the music, then construct a Div.

Use editor.setPart('tab') to show just the frets and editor.setPart('score') to restore both staves. Omit editor="true" for a read-only score. Call editor.dispose() when the component unmounts.

Draw into your own preview

If your app already has a text editor, parse its value and draw the result into an empty preview element. Catch ScoreV2Error to select the offending text. This example accepts a textarea and a preview element.

For validation in Node.js, import parseScore from vextab/parse. To engrave a printed part, pass the parsed score to renderScorePart.

Enable and configure playback

The player in this guide adds browser audio, a moving playhead and a choice of instruments. Install the 6.1.0 package in your app to use the browser playback adapters.

Play a bar

Add a play block before the first part in your embed. Press Play to start audio and Stop to end it. Try changing tempo 96 to tempo 72 in the example below, then play again.

play { tempo 96 instrument 24 }
meter 4/4
guitar {
  :q 0/1 2/1 3/1 2/1 |
}

tempo sets quarter-note beats per minute. instrument accepts a General MIDI program from 0 to 127 or a name such as acoustic_guitar_nylon. A fresh embed uses native Web Audio for a synthesized tone. This guide uses SpessaSynth and a bundled SoundFont, so you can hear sampled instruments here.

Enable the sheet controls from JavaScript

Pass { player: true } to Div to enable playback for any source. Play and Stop share a button at the bottom center of the visible sheet. The buttons follow the score as you scroll. They fade after three seconds of pointer inactivity and reappear when you move over the music, tap it, or tab to a control. Hover over the metronome beside Play, or activate it with a tap or keyboard, to change the tempo.

This example keeps the large panel visible. Use size: 'mini' for compact buttons, or size: 'auto' to let the score choose. The default large panel has an Auto-scroll toggle for following the active system. Use visibility: 'hover' for the default reveal behavior, or playbackControls: false to hide them. You can also put controls always controlSize large position top-right inset 16 in the score’s play block, or set data-playback-controls="always", data-playback-size="large" and data-playback-position="top-right" on the embed.

To use your own SoundFont, load it into a connected SpessaSynth synthesizer, then pass playback: createSpessaSynthPlayback(synth) alongside player: true. For custom buttons, call player.play() from a click handler and player.stop() to cancel. See the Player API and the SpessaSynth setup and examples.

Play a SoundFont with SpessaSynth

Give a score the sound of a sampled guitar, violin or marimba. Your app supplies the sound bank and the browser’s audio output. VexTab sends the written pitches, durations and bends to SpessaSynth.

Hear the instrument change

Press Play to hear a nylon-string guitar. The open bass stays steady while the other string releases its bend. Change instrument 24 to instrument 40 for violin or instrument=12 for marimba, then play it again.

play { tempo 84 instrument 24 }
meter 2/4
guitar {
  :q (0/6 7/3[prebend +1 release]) 7/3 |
}

Serve the worklet and sound bank

Start with the VexTab source build with playback support. Install the synth in your app and copy its matching audio processor into your public assets. This example downloads the same public-domain SF2 bank used by the guide.

Serve public/audio/ at /audio/ over HTTPS or localhost so the browser can start an AudioWorklet. To use a different bank, substitute its SF2 file and choose a program it contains.

The four MIDI channels in this example are reserved for VexTab. A bent note needs its own channel so its pitch change leaves the bass alone. Reuse the same playback adapter for scores sharing a synth. Omit the channel list to use the default pool of 15 melodic channels.
