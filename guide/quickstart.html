Get VexTab on a page

To put an editable guitar score on a plain HTML page, download the browser bundle into an empty directory. It contains VexTab, VexFlow and the engraving fonts, so you can open this first example directly from disk.

Save the following as index.html beside div.prod.js, then open it in your browser. The script finds the vextab-auto element and turns the music inside it into a score and editor.

Find the four quarter notes and their matching frets. Change 3/1 to 5/1 and press Ctrl+Enter or Cmd+Enter. The third note moves from G to A. If the page shows only the source text, check that the script filename and its location match the HTML.

These examples use grammar v2, the default in VexTab 6. To read scores written for the VexTab 5 grammar, set data-language="1" on the host or pass { language: 1 } to the parser. To update the music itself, follow the score migration guide.

In an app with a bundler, importing vextab/auto mounts the same markup. If your component creates the host after the page loads, mount the editor from JavaScript.

Embed a score in your code

To mount the same four notes in a component, install the package in your app and import Div from vextab/browser. Add the host to the page before running the JavaScript so the editor can measure its width.

Call editor.setPart('tab') to read the four frets alone and editor.setPart('score') to bring back the staff. Omit editor="true" for a read-only score. When the component leaves the page, call editor.dispose() to release its observers and player.

Draw into your own preview

If your app already owns the textarea, pass its value to parseScore and give the result to renderScore. Call this function with the textarea and an empty preview element. On a grammar error it selects the offending characters and returns a message your app can display.

A validator that only needs the parsed music can import parseScore from vextab/parse in Node.js. In a browser you can also use that parsed score to print an individual part.

Enable and configure playback

The browser package can play an embedded score through Web Audio. Install the built package in your app directory to use the JavaScript examples below. The interactive example here uses the guide’s sampled guitar.

Play a bar

Put the tempo and instrument in a play block before the guitar part. Press Play, then stop and change tempo 96 to tempo 72. The four notes keep their pitches and take longer to finish.

play { tempo 96 instrument 24 }
meter 4/4
guitar {
  :q 0/1 2/1 3/1 2/1 |
}

Tempo counts quarter notes per minute. Select an instrument with a General MIDI program from 0 to 127 or a name such as acoustic_guitar_nylon. An embed supplies a synthesized Web Audio tone by default. To hear the instrument samples used here, connect a SoundFont as shown in the next chapter.

Enable the sheet controls from JavaScript

An app can enable playback even when the music has no play block. Pass player: true when constructing the editor. By default, Play and the metronome sit at the bottom center of the visible score. Move over the sheet, tap it or focus a control to reveal them. After three seconds with the pointer still, the hover panel fades.

This example keeps the large panel in the upper right, 16 pixels from the edge. Its auto-scroll button starts enabled and follows the playing system. Use size: 'mini' for compact controls, size: 'auto' to choose by score height, or playbackControls: false to hide them. You can also write controls always controlSize large position top-right inset 16 inside the score’s play block. The control options describe the defaults.

For your own Play and Stop buttons, call player.play() from a click handler and player.stop() to end the performance. To change how the notes sound, supply a playback adapter. See the Player API and the working SpessaSynth example.

Play a SoundFont with SpessaSynth

A SoundFont is a bank of recorded instrument samples. In this example the browser supplies the audio output, SpessaSynth plays the samples, and VexTab tells it when to start, bend and release each note.

Hear the instrument change

Press Play and listen for the upper guitar string to release its bend over the steady open bass. Change instrument 24 to instrument 40 for violin or instrument 12 for marimba. Replay the bar to hear the new instrument play the same pitches.

play { tempo 84 instrument 24 }
meter 2/4
guitar {
  :q (0/6 7/3[prebend +1 release]) 7/3 |
}

Serve the worklet and sound bank

Start in a browser app with a bundler and the VexTab package installed. Install SpessaSynth, copy its matching worklet into your public directory, then download the small public-domain sound bank used in this guide.

Serve public/audio/ at /audio/ over HTTPS or localhost. The worklet runs the synthesizer on the browser’s audio thread. If you substitute another SF2 bank, choose a program that bank contains.
